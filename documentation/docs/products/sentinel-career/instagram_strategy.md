# Estratégia Instagram Sentinel Career

## Objetivo
Criar visibilidade de marca e conversão para cadastro

## Táticas
- Reels de dicas rápidas de carreira
- Carrosséis explicativos de passos
- Stories com CTAs (cadastre-se, tire dúvida)
- Depoimentos de usuários
- Mostrar recursos premium visualmente

## Frequência
- 4x por semana (reels/stories alternados)

## Métricas
- Visitas no perfil
- Conversão para cadastro no site
- Engajamento em reels/carrosséis
